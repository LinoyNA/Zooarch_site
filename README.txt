ZooArchaeology for Kids — standalone website
=============================================

This folder contains your complete website, independent of Wix:
  index.html        → the website itself
  images/           → all photos used on the site
  README.txt        → this file

HOW TO VIEW IT
  Double-click index.html to open it in any web browser.

HOW TO PUT IT ONLINE FOR FREE
  Easiest option — Netlify Drop:
    1. Go to https://app.netlify.com/drop
    2. Drag this whole folder onto the page.
    3. You get a free live link instantly (e.g. yourname.netlify.app).

  GitHub Pages:
    1. Create a free account at github.com
    2. Make a new repository, upload these files.
    3. Settings → Pages → enable. Your site appears at
       username.github.io/repository-name

SEO (added)
-------------------------------------------------
Included: sitemap.xml, robots.txt, Open Graph + Twitter
cards, and Schema.org structured data inside index.html.

IMPORTANT — set your real address:
  Once you know your final site URL (e.g. https://USERNAME.github.io
  or your own domain), open index.html, robots.txt and sitemap.xml
  and replace every  https://www.zooarchforkids.com  with it.

After publishing, add the site (free) to Google Search Console
(search.google.com/search-console) and submit sitemap.xml so Google
indexes it.
